# 每日听歌插件 · 黑箱测试清单

> 版本：dsh-netease-daily 0.2.0+ ｜ 环境：DSH Desktop 0.2.1-rc.2（Windows）
> 原则：只验证外部可观察行为（界面、消息、文件、声音、进程窗口），不读插件源码、不假设内部实现。
> 判定：每条用例记录 P（通过）/ F（失败）+ 现象截图或文字证据。

## 0. 测试范围

| 面 | 覆盖内容 |
|---|---|
| 设置页 | 面板可见、配置项可改、保存生效、重启保留 |
| 依赖 | mpv 状态显示、检测、回退提示 |
| 登录 | 二维码生成、扫码确认、登录状态与保持 |
| 定时运行 | 到点自动执行、结果消息格式、静默（无声音/无窗口） |
| 推荐与评价 | 3 首推荐、每首评分与理由、评价写入日志 |
| 日志 | 指定目录落盘、latest.md / index.html、30 天保留 |
| 异常 | 未登录、播放器未就绪、日志目录不可写 |
| 唤起客户端 | 已安装直接唤起客户端；未安装回退网页并提示 |

不在范围内：模型挑歌质量、歌词准确性、VIP 版权判定（属外部服务）。

## 9. 唤起网易云客户端（本次新增）

| ID | 步骤 | 预期 | 判定 |
|---|---|---|---|
| I1 | 已安装网易云客户端：在「最近推荐」点歌名 | 直接唤起客户端并开始播放该曲目 | P/F |
| I2 | 未安装客户端：点歌名 | 浏览器打开网页版，并在面板显示「未检测到客户端，已回退网页版」提示 | P/F |
| I3 | 点歌曲右侧「网页」按钮 | 始终用浏览器打开网页版 | P/F |
| I4 | 对话里说「打开第 2 首」 | 走同样逻辑：客户端优先，否则网页回退并说明 | P/F |
| I5 | 观察链接 | 唤起使用 `orpheus://song/<id>/`，回退使用 `https://music.163.com/#/song?id=<id>` | P/F |

**在没有安装客户端时验证 I1（可回滚的测试夹具）**

```powershell
# 1) 临时注册一个假 orpheus 协议，处理器把收到的 URL 写进标记文件
reg add "HKCU\Software\Classes\orpheus" /ve /d "URL:orpheus Protocol" /f
reg add "HKCU\Software\Classes\orpheus" /v "URL Protocol" /d "" /f
reg add "HKCU\Software\Classes\orpheus\shell\open\command" /ve /d "cmd /c echo %1 > \"%TEMP%\orpheus-test.txt\"" /f
# 2) 在面板点一次歌名（或在对话里说「打开某首歌」）
# 3) 检查标记文件内容应为：orpheus://song/<id>/?autoplay=1
Get-Content "$env:TEMP\orpheus-test.txt"
# 4) 清理（务必执行）
reg delete "HKCU\Software\Classes\orpheus" /f
Remove-Item "$env:TEMP\orpheus-test.txt" -Force -ErrorAction SilentlyContinue
```

预期：标记文件里正是 `orpheus://song/<id>/?autoplay=1`，且面板提示「已唤起网易云音乐客户端」——说明深链拼装与系统协议调用都正确；之后面板状态应恢复「未检测到客户端」。

## 10. 点歌直接播放（经典桌面版，调试通道）

| ID | 步骤 | 预期 | 判定 |
|---|---|---|---|
| K1 | 关闭网易云客户端；在「最近推荐」点歌名 | 客户端被启动（带 `--remote-debugging-port=9223`），自动搜索并开始播放该歌曲，面板提示「已唤起网易云音乐并在客户端里播放「歌名」」 | P/F |
| K2 | 保持客户端运行；再点另一首歌 | 在新打开的动作后切换到该歌曲（无需重启客户端） | P/F |
| K3 | 从开始菜单手动启动客户端（无调试通道）后点歌名 | 客户端被唤起，歌名复制到剪贴板，提示里说明「关掉客户端后下次点歌即可直接播放」 | P/F |
| K4 | 点「网页」按钮 | 始终用浏览器打开网页版，不操作客户端 | P/F |
| K5 | `netease_status` 查看 `client` 字段 | 经典版返回 `kind:"protocol"` 且带 `exe` 路径 | P/F |
| K6 | 关闭客户端后重新从开始菜单启动并点歌 | 首次走深链/复制歌名；关掉客户端后再次点歌恢复直接播放 | P/F |
